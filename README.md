# 별빛 사주 ✦

생년월일시로 사주팔자·오행 분포·주제별 운세를 부드럽게 풀어주는 힐링 스타일 웹사이트입니다.

## 특징

- **사주 계산**: `saju-fortune` 스킬의 계산 로직(년·월·일·시주, 오행 분포, 일간 강약, 조율점)을 브라우저용 JavaScript로 옮겨 서버 없이 동작합니다.
- **운세 주제**: 종합운 · 재물운 · 연애운 · 직업운 · 건강운
- **시각화**: 사주 네 기둥 카드, 오행 분포 애니메이션 바, 일간 카드
- **디자인**: 파스텔 핑크 + 크림 아이보리, 보름달과 토끼 배경 일러스트, 둥근 모서리, 귀여운 필기체(Gaegu)

## 구조

```
byeolbit-saju/
├── index.html        # 화면 구조
├── assets/
│   ├── style.css     # 디자인 시스템 (색·타이포·컴포넌트)
│   └── app.js        # 사주 계산 + 렌더링
└── README.md
```

## 로컬에서 보기

`index.html`을 브라우저로 바로 열어도 되고, 로컬 서버로 열어도 됩니다.

```bash
npx serve .
```

## 참고

- 양력 생년월일 기준으로 계산합니다. 음력은 만세력으로 양력 변환 후 입력해야 합니다.
- 태어난 시각을 모르면 연·월·일 세 기둥으로 보수적으로 해석합니다.
- 사주 풀이는 자기점검용 전통 해석이며, 의료·투자·법률 판단을 대신하지 않습니다.
